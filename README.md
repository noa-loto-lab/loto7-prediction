# ロト7予想ツール(第2段階:数字選択機能を追加)

## ファイル構成
```
index.html / style.css / app.js
```
3ファイルを同じフォルダに置きます(例:リポジトリの `loto7/` フォルダ)。既存の「航海図メーカー」のファイルとは別フォルダにしてください。

## 公開手順(GitHub Pages)
1. GitHubの既存リポジトリに `loto7` フォルダを作り、3ファイルをアップロードしてコミットします。
2. Settings → Pages で公開が有効になっていることを確認します(既存設定のままでOK)。
3. 数分後、`https://<ユーザー名>.github.io/<リポジトリ名>/loto7/` を開きます。

## iPhone横向きでの確認手順
1. 上のURLをSafariで開き、iPhoneを横向きにします(画面の向きのロックは解除しておく)。
2. 画面上部に1〜37の見出し、中央に出目表、下部に次回予想欄が見えることを確認します。
3. 出目表を上下にスワイプ → 出目表だけが動き、見出しと予想欄は動かないこと。
4. 出目表・見出し・予想欄のどれかを左右にスワイプ → 3つが一緒に動き、どの位置でも同じ数字の列が上下で揃うこと。
5. 斜めにスワイプしても、ページ全体が動かないこと。
6. 「第○回」「次回予想」の文字が数字マスと重ならず、途中で切れていないこと。
7. 共有ボタン → 「ホーム画面に追加」で追加すると、Safariのバーなしで全画面確認できます。

## 今回実装した内容
- 画面3領域(数字見出し / 過去の出目表 / 次回予想欄)の基本レイアウト
- 1〜37の数字見出し、左端の開催回の列(横スクロール中も左に固定)
- 仮データ(第660〜699回、新しい回が下)による出目表と縦スクロール
- 次回予想欄の下部固定
- 上下で連動する横スクロール(列幅は `style.css` の `--round-w` と `--cell-w` に一本化)
- ページ全体のスクロール・バウンスの抑止、横向きの安全領域への対応

## 第2段階で追加した内容
- 次回予想欄の1〜37のマスをタップすると選択(オレンジ地・白い太字の数字・白い内枠で表示)。もう一度タップで解除
- 選択は最大7個。7個選択済みのときに別のマスをタップしても追加されず、選択数表示が小さく揺れる
- 画面最上段の独立した操作エリアに選択数を「0 / 7」〜「7 / 7」で表示(7個で色が変わる)。この帯は横スクロールしない。同じ1行に、選択した数字を小さい順の小さなラベルで表示し、「全解除」も小型化(見た目は小さく、タップ範囲は広めに確保)。数字が収まらない場合はラベル部分だけが横スクロールし、2行にはならない。出目表の最下段と次回予想欄の間には何も挟まない
- 「全解除」ボタンで選択をすべて解除(選択が0個のときは押せない状態)
- 変更点:`index.html`(選択数の帯を追加)、`style.css`(帯と選択状態のスタイルを追加、画面の行数を3→4に)、`app.js`(予想欄のマスにデータ属性を付与、選択処理を追加)。第1段階のスクロール・同期処理は変更していません

## 第2段階 iPhone確認項目(横向き)
1. 第1段階の確認(出目表の縦スクロール、上下の横スクロール連動と列の一致、予想欄の下部固定、文字の重なりなし)が今までどおりであること。
2. 予想欄のマスを1つタップ → 選択表示になり、数字が出て、選択数が「1 / 7」になること。
3. 選択中のマスをもう一度タップ → 解除され、選択数が減ること。
4. 7個まで選択 → 「7 / 7」になること。8個目をタップしても追加されず、選択数表示が揺れること。
5. 7個選択済みの状態で1つ解除 → 別の数字を選択できること。
6. 予想欄を左右にスワイプしてスクロール中、意図せずマスが選択されないこと。
7. 横にスクロールした位置(右端の37付近など)でも、タップした数字のマスが正しく選択されること。
8. 「全解除」で、選択がすべて消えて「0 / 7」に戻ること。
9. 出目表の縦スクロール領域が狭くなりすぎていないこと(最上段の操作エリアの分、約26px低くなっています)。
10. 選択のオン・オフの操作中に、ページ全体が動かないこと。

## 調整したいとき
マスの大きさは `style.css` 冒頭の `--cell-w`(列幅)、`--row-h`(行の高さ)、`--round-w`(開催回の幅)で変更できます。

## 追加:「最新回へ戻る」ボタン
- 最上段の操作エリア(「全解除」の左隣)に小さく配置。押すと出目表が縦方向だけ最新回(最下段)の位置へ戻る。横スクロール位置、選択した数字、選択数は変わらない。
- 確認方法(iPhone横向き):①出目表を上へスクロールして古い回を表示 → ②「最新回へ戻る」をタップ → 最新回が見える位置へ戻る ③横にスクロールした状態で押しても、数字の列が上下で揃ったままで、横位置が変わらない ④数字を選択した状態で押しても、選択と「n / 7」が変わらない。
