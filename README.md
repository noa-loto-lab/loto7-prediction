# ロト7予想ツール(第1段階:画面レイアウトとスクロール)

## ファイル構成
```
index.html / style.css / app.js
```
3ファイルを同じフォルダに置きます(例:リポジトリの `loto7/` フォルダ)。既存の「航海図メーカー」のファイルとは別フォルダにしてください。

## 公開手順(GitHub Pages)
1. GitHubの既存リポジトリに `loto7` フォルダを作り、3ファイルをアップロードしてコミットします。
2. Settings → Pages で公開が有効になっていることを確認します(既存設定のままでOK)。
3. 数分後、`https://<ユーザー名>.github.io/<リポジトリ名>/loto7/` を開きます。

## iPhone横向きでの確認手順
1. 上のURLをSafariで開き、iPhoneを横向きにします(画面の向きのロックは解除しておく)。
2. 画面上部に1〜37の見出し、中央に出目表、下部に次回予想欄が見えることを確認します。
3. 出目表を上下にスワイプ → 出目表だけが動き、見出しと予想欄は動かないこと。
4. 出目表・見出し・予想欄のどれかを左右にスワイプ → 3つが一緒に動き、どの位置でも同じ数字の列が上下で揃うこと。
5. 斜めにスワイプしても、ページ全体が動かないこと。
6. 「第○回」「次回予想」の文字が数字マスと重ならず、途中で切れていないこと。
7. 共有ボタン → 「ホーム画面に追加」で追加すると、Safariのバーなしで全画面確認できます。

## 今回実装した内容
- 画面3領域(数字見出し / 過去の出目表 / 次回予想欄)の基本レイアウト
- 1〜37の数字見出し、左端の開催回の列(横スクロール中も左に固定)
- 仮データ(第660〜699回、新しい回が下)による出目表と縦スクロール
- 次回予想欄の下部固定
- 上下で連動する横スクロール(列幅は `style.css` の `--round-w` と `--cell-w` に一本化)
- ページ全体のスクロール・バウンスの抑止、横向きの安全領域への対応
